## Outcome

AGENTS/Heavy/delegation and directly affected tests expose one coherent six-role direct-to-Main contract, with bounded Explorer discovery and exactly-three-lane Investigator research for every qualifying bounded Investigator problem.

## Scope

### Included
- Reconcile `codex_workflow/AGENTS.md`, `codex_workflow/heavy_route.md`, `codex_workflow/delegation.md` and directly affected runtime/contract tests.
- Remove Early Companion / Companion lifecycle and Micro Execution routing as active workflow concepts.
- Define Explorer as bounded read-only project-context discovery/mapping/evidence retrieval used when broader context discovery reduces Main context load.
- Define Investigator for bounded fault hypotheses, solution alternatives, feasibility and prior-art research.
- Require exactly three independent Investigator lanes for each bounded problem that qualifies for Investigator: one shared Problem ID, distinct Task IDs, complementary angles, no inter-lane coordination, and Main comparison of evidence/disagreement rather than voting.
- Require all worker final results to return directly to Main; remove direct sibling-message permissions/exceptions.
- Replace fixed word ceilings in orchestration/reporting text with smallest-complete evidence-linked decision-ready reporting and references to bulky logs/diffs.

### Excluded
- Profile-count reduction, removal of `luna-xhigh`/`pro-x5`, final plus-only Material Event Push semantics and remaining Muse profile/runtime cleanup owned by M03.
- M04 public-document rename/deep-dive adaptation.
- VERSION/release-triggering changes or publication.

## Acceptance

- Active AGENTS/Heavy/delegation contracts name only Explorer, Investigator, Default Executor, Senior Executor, Tester and Archivist as supported workers.
- No active contract bootstraps/persists Companion or routes Micro Executor.
- Explorer and Investigator responsibilities match REQ-006 without overlap that recreates Companion.
- Every qualifying Investigator problem is specified as exactly three independent lanes with shared Problem ID, distinct Task IDs and complementary angles; Main compares evidence and disagreement, never lane votes.
- Worker final results route directly to Main; no active contract permits direct sibling messaging.
- Active reporting contracts contain no fixed hard word-count ceilings and require smallest complete evidence-linked decision-ready returns with bulky logs/diffs referenced rather than reproduced.
- Tester independence, Senior Executor/Archivist availability, proportionate documentation intake and existing Muse session-safety/repair ordering remain intact.
- Medium route and Deployment Token Report remain absent; VERSION/release markers remain unchanged.
