## Outcome

Produce durable, independently reviewable live evidence establishing whether the smallest native Codex path can keep one controlled multi-minute wait inside a single outer Code Mode cell without periodic Main/model sampling, while retaining safe interruption/cancellation behavior.

A GREEN result selects the native one-cell path for JIT implementation preparation. A RED result must identify the exact host/runtime limitation precisely enough for Execution Prep to evaluate the already-authorized DEC-006 managed-wait fallback without inventing implementation detail.

## Scope

### Included

- An isolated controlled long-running command, lasting at least two minutes for the healthy-wait probe.
- One outer Code Mode `exec` cell that owns the controlled command lifecycle.
- Internal terminal-session waits inside that same cell after the ordinary initial terminal yield boundary.
- Codex-LB request-count evidence for the healthy interval.
- Matching Codex rollout/tool evidence proving whether Main was or was not re-entered for liveness.
- A bounded interruption/cancellation trial and process-tree teardown readback.
- Sanitized durable evidence sufficient for independent review.

### Excluded

- Production event-driven Muse wait implementation.
- Dedicated managed wait/tool/broker fallback implementation.
- Quiet-milestone communication changes.
- Release/version/tag/GitHub Release changes.
- External/live deployment beyond authorized local workstation verification.
- Raw private Muse trajectories, credentials or unrelated conversation/log contents.

## Acceptance

- The controlled healthy wait lasts at least 120 seconds.
- The whole healthy wait is owned by one outer Code Mode cell; any required terminal-session waits repeat inside that cell rather than returning to Main between liveness checks.
- Codex-LB shows no increase in Main request count during the healthy wait interval, excluding explicit user input or a genuinely material runtime event.
- Matching rollout/tool evidence contains no recurring Main-driven terminal/session liveness loop for that interval.
- The controlled command reaches normal terminal completion through the native path.
- A separate interruption/cancellation trial confirms bounded teardown with no surviving controlled child/process tree.
- Durable evidence explicitly accounts for every REQ-024 sub-invariant: timeout/cancellation cleanup, logical-session binding, fail-closed resume/replacement, Executor/Tester independence and private raw-artifact isolation, distinguishing directly exercised properties from preserved/not-mutated properties.
- No `plus` implementation/profile behavior is changed.
- Repository source remains unmodified by the probe except for Project Workflow Card/state/evidence artifacts.
- If the native gate is RED, evidence identifies the concrete native-host limitation and does not itself implement the fallback.

## Required tests / checks

- Pre-probe branch/source-state readback.
- Live >=120-second native one-cell healthy-wait probe.
- Codex-LB request-count comparison across the healthy interval.
- Exact rollout/tool-call inspection for the same interval.
- Controlled interruption/cancellation and process-tree readback.
- Post-probe repository/source-state readback.
- REQ-024 invariant checklist in durable evidence.
